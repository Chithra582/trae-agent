# Multi-LLM Routing Adapter

## Overview
The `multi-llm-routing-adapter` skill unifies model interfaces across proprietary and open-source foundation models, optimizing cost, latency, and context capacity for software engineering workloads.

## Supported Providers
- **Anthropic Claude 3.5 / 3.7 Sonnet:** Recommended for complex multi-file refactoring and architectural planning.
- **OpenAI GPT-4o / o1:** Optimal for formal logic reasoning and algorithmic optimization.
- **Doubao & DeepSeek:** High-throughput reasoning and cost-effective batch testing.
- **Google Gemini 2.5 Pro:** Extreme context window tasks spanning complete repositories.
