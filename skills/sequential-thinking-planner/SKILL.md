# Sequential Thinking Planner

## Overview
The `sequential-thinking-planner` skill guides structured hypothesis testing when debugging elusive bugs, refactoring legacy components, or implementing multi-file features.

## Planning Phases
1. **Problem Formulation:** Articulate root cause hypotheses and observable symptoms.
2. **Reproduction Harness:** Formulate minimal reproducible test cases before touching production code.
3. **Branching Hypotheses:** Maintain alternative problem hypotheses if initial investigation contradicts expectations.
4. **Termination Criteria:** Explicitly define success conditions (e.g., test suite passes, zero lint warnings).
